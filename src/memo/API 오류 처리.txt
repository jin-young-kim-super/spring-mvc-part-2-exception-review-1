API의 오류 처리와 오류 페이지의 차이점
-> 오류 페이지는 사용자가 웹 브라우저에서 요청시 만약에 404에러 발생 시 개발자가 만들어 놓은 404에러 페이지를 보여주기만 하면 끝이다.
그러나 API의 경우 그렇게 단순하지가 않다. API의 경우 예를 들어 앱과 통신할 수도 있고 기업과 기업간의 API 통신도 가능하고, 더 나아가 MSA에서 서버와 서버끼리 API 통신도 가능하다. 
즉 API는 웹 브라우저를 통해서 통신을 하는 것이 아니기 때문에 오류 페이지를 보여줘도 클라이언트 쪽에서 HTML 페이지를 해석할 방법이 없다.
그래서 클라이언트와 미리 약속된 API 오류 스펙(주로 JSON)을 보내 줘야 한다. 그래야 API 오류 응답을 받은 클라이언트에서 오류 내용을 해석할 수가 있다.
