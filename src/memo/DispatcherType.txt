WAS는 예외 발생, response.sendError(4xx,5xx) 발생 시, 다시 컨트롤러를 호출을 하는데 이때 필터, 인터셉터를 다시 한 번 중복으로 거치게 된다. 
이는 매우 비효율적이다. 
그래서 탄생한 개념이 바로 DispatcherType이다(requet.getDispatcherType()).
DispatcherType을 통해 서버가 아 이 요청은 클라이언트로부터의 새로운 요청인지 아니면 WAS가 오류를 만나 서버 내부에서 재요청한건지를 구분할 수가 있게 되었다. 

DispatcherTYpe : ERROR
-> 에러에 의한 서버 내부 재요청

DispatcherTYpe : REQUEST
-> 클라이언트로부터의 새로운 요청
